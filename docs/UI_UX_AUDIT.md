# UI/UX刷新レポート

**対象:** YAKU-IKU-POCKET  
**実施日:** 2026-09-02  
**目的:** 既存機能、安全表現、アクセシビリティを維持しながら、モバイル・タブレット・Webで一貫した「Living Field Guide」体験へ引き上げる。

## 総括

現行アプリは、森林色を中心としたブランド、安全性を色だけに依存しない表示、44pt以上の主要操作領域、Dynamic Type、VoiceOver、Reduce Motionなど、良質な基盤を備えていた。一方、画面幅が広い環境ではコンテンツが横いっぱいに伸び、カード、本文、タブバーの視線移動が長くなる課題があった。また、初回状態では未発見カードや未達成実績が反復し、ユーザーの次の行動より情報量が先に立つ画面があった。

今回の刷新では、装飾を増やすのではなく、**読み幅、情報の優先順位、状態の意味、次の行動**を改善した。共通レイアウトトークンと中央寄せフレームを導入し、主要画面を用途別の最大幅へ統一した。観察権限画面は許可後の流れを理解できる信頼カードへ、探索カードは未発見状態にも学習価値がある表現へ、記録画面は実績の段階表示と明確な空状態CTAを持つ構成へ変更した。

## 主な改善

| 領域 | 改善内容 | UX上の効果 |
|---|---|---|
| 共通レイアウト | 1120px、920px、640pxの用途別最大幅トークンと`ResponsiveFrame`を導入 | タブレット・Webで行長とカード幅が安定し、視線移動が短くなる |
| Web基盤 | 外側背景、ライト・ダークのカラースキーム、文字選択色を追加 | 中央寄せされたアプリ面が明確になり、ブラウザ上の完成度が上がる |
| ナビゲーション | Web上の各タブ項目に最大幅を設定 | 大画面でもタブ間隔が過度に広がらない |
| 今日 | 季節の注目植物を画面幅に応じて4〜6件へ抑え、「すべて探す」を追加 | 初回状態の反復感を減らし、探索への次アクションを明確化 |
| 観察 | 権限理由、主CTA、撮影の三段階、安全注記を最大幅640pxのカードへ再構成 | カメラ許可後の体験を予測しやすくなり、広い画面の空白感も解消 |
| 探す | 一覧幅とグリッド計算を最大幅に連動し、未発見カードを「未発見＋科名」に変更 | 謎要素を保ちながらカードの意味と学習価値が向上 |
| 記録 | 最大幅920px、カレンダー最大幅720px、実績4件プレビュー、空履歴CTAを導入 | 長い画面を短縮し、観察履歴と次の行動を見つけやすくする |
| 植物詳細 | ヒーロー、発見情報、本文を最大幅920pxへ統一し、注意バナーのコントラストを強化 | 長文の可読性、安全情報の発見性、カード階層が向上 |
| モーション | 植物カードの押下を短い`timing`へ変更し、Reduce Motionを維持 | 反応が速く、落ち着いたフィールドノート体験になる |

## アクセシビリティ

既存の読み上げラベル、選択状態、展開状態、フォーカス復帰、Reduce Motion、大きな文字への対応を保持した。新規の「すべて探す」「すべて見る」「最初の観察を始める」には明示的なアクセシビリティラベルを設定した。未発見カードは画面上の科名を短縮しても、読み上げでは完全な科名と希少度を伝える。観察権限画面の三段階ガイドは、視覚上は三つのカード、読み上げ上は一つの順序立った説明として提供する。

## 品質検証

`npm run check`を実行し、TypeScript、ESLint、Jestを通過した。テストは**24スイート、167件すべて成功**している。続いて`npm run build:web`を実行し、主要ルートを含む11の静的ルートが正常にエクスポートされた。`git diff --check`でも空白エラーは検出されていない。

## 変更しなかった領域

今回の刷新では、識別ロジック、植物データ、AI送信条件、XP・チャレンジ計算、永続化、観察履歴、安全文言を変更していない。UI/UXの品質向上に範囲を限定し、既存の安全性とデータ挙動を維持した。
