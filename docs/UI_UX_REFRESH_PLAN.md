# UI/UX刷新方針

**対象:** YAKU-IKU-POCKET  
**方針:** 既存機能、安全表現、Dynamic Type、VoiceOver、Reduce Motion、データ保存挙動を維持しながら、モバイル・タブレット・Webで一貫した「Living Field Guide」体験へ引き上げる。

## デザイン判断

今回の刷新では、装飾を増やすのではなく、**視線移動、情報の優先順位、状態の理解、入力への確信**を改善する。現行の森林色、自然史ノートの語彙、安全性を色だけに依存しない原則は維持する。一方、画面幅に応じてコンテンツが無制限に広がる問題、反復カードによる視覚ノイズ、重要な履歴が下方へ埋もれる問題を解消する。

| 領域 | 現状の課題 | 刷新方針 | 完了条件 |
|---|---|---|---|
| 共通レイアウト | Web・タブレットで本文が全幅化する | 中央寄せの最大幅コンテナと用途別の読み幅を導入する | 390px、768px、1024px以上で行長とカード幅が安定する |
| ナビゲーション | デスクトップでもタブバーが全幅になる | Webではナビゲーションを中央寄せし、観察タブの主役感を維持する | 選択状態、フォーカス、タップ領域が明確である |
| 今日 | 情報量が多く、初回状態では未発見カードが反復する | 主CTA、季節、次の行動、進捗の順に階層化する | 最初の画面で「何をすべきか」が一意に理解できる |
| 観察 | 権限前状態が広い余白に孤立する | 権限理由、撮影の流れ、安全説明を一つの信頼カードへまとめる | 権限を許可する判断材料と次の体験が分かる |
| 探す | 150件の未発見カードが即時に反復する | ヘッダー、検索、絞り込み、結果件数を探索ワークスペースとして統合し、カードの情報階層を整理する | 検索・フィルター・表示切替が近接し、一覧の走査が容易である |
| 記録 | 実績・設定が履歴より強く、カレンダーが過大化する | 履歴を主役とし、補助情報は読み幅を制限して段階表示する | 空状態でも観察開始への次アクションが明確である |
| 植物詳細 | ヒーローと本文が全幅化し、安全区分が埋もれる | 読み幅を狭め、安全区分、識別、出典、メモを明瞭に分離する | 長文の可読性と安全情報の発見性が向上する |

## 実装原則

すべての主要CTAは44pt以上のタップ領域、押下状態、無効状態、読み上げラベルを維持する。Webではキーボードフォーカスが視覚的に確認でき、モーダル終了後は元の操作位置へ戻る。大きな文字では2列・横並びを必要に応じて1列へ切り替え、テキストを固定高で切らない。安全区分、希少度、観察済み状態は色だけでなく、ラベル、アイコン、形状を併用する。

## 今回の実装範囲

共通のレスポンシブコンテナを新設し、ホーム、観察権限画面、探索、記録、植物詳細へ適用する。あわせて、観察権限カードの再構成、探索カードと結果コントロールの密度調整、プロフィールのカレンダーとセクション幅の最適化、Web向けタブバーの中央寄せを行う。識別ロジック、植物データ、課題・XP、永続化、AI送信条件、安全文言は変更しない。
