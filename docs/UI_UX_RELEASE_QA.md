# UI / UX Release QA

薬育ポケットのUI/UX品質を、特定の端末・文字サイズ・視覚条件だけで成立するものにしないためのリリース前チェックリストです。

## 合格原則

- 主要操作は原則 44 x 44 pt 以上の実タップ領域を持つ。
- 情報の意味を色だけで伝えない。状態には文字、アイコン、形、読み上げ状態のいずれかを併用する。
- 通常サイズの本文・補助文字は背景とのコントラスト 4.5:1 以上を基準にする。
- Dynamic Type を上げても、重要な本文・安全情報・保存/閉じる操作が画面外へ到達不能にならない。
- Reduce Motion 有効時に、情報理解へ不要なループ/祝福アニメーションへ依存しない。
- VoiceOver / TalkBack で、見えている意味と読み上げられる意味を一致させる。
- Modalやページ遷移後は、閉じる操作ではなく新しく現れた内容の見出し・判断文脈から理解を始められる。
- AIの候補を「確定」「安全」と誤認させる文言・色・演出を使わない。
- 危険情報はスクロールの奥だけに置かず、判断前に確認できる位置へ出す。
- キーボード、Safe Area、ホームインジケータ、ステータスバーで主要操作を隠さない。
- 空状態・失敗状態・権限拒否状態から、ユーザーが次に取る行動を明確にする。
- 複数ページの導入・確認フローは、誤操作しても前の内容へ戻って読み直せる。
- 写真など明度が予測できない背景上の文字は、scrim・surface・影などで背景依存の可読性を避ける。
- 日付更新やアプリ復帰のためだけに、現在のタブ・入力途中の状態・スクロール文脈を不必要に失わせない。
- 安全説明が必要な画面では共有 `DisclaimerBanner` を使用し、「必ず専門家に確認を」の文言を視覚・読み上げの両方で維持する。

## 端末マトリクス

最低限、次の幅/高さ条件で主要4タブと植物詳細を確認する。

| 条件 | 重点確認 |
| --- | --- |
| 小型iPhone相当（約375 x 667） | カメラ操作、下部CTA、Modal、図鑑2列、キーボード |
| 標準iPhone相当 | 基準レイアウト、Safe Area、タブバー |
| 大型iPhone相当 | 過度な余白、カード最大幅、ヒーロー密度 |
| Android小型端末 | 戻る操作、キーボード、権限拒否、ナビゲーションバー |
| 低い横画面 / split view | Modal本文がスクロールし、閉じる/次へ/確認CTAが到達可能 |
| Web narrow viewport | タッチUIの崩れ、スクロール、Modal |
| Web wide viewport | カード過伸長、情報密度、最大幅 |

- [ ] 今日タブのヒーロー、達成バナー、カード、XP表示のコントラストが十分
- [ ] 今日タブの小さいFIELD NOTE・プレイヤー名・補助文がHeroグラデーションの全域で読める
- [ ] 観察タブのカメラ上オーバーレイが写真背景に依存せず読める
- [ ] 観察結果の写真背景上で、植物名・英名・学名・補助ラベルが読める
- [ ] 探すタブの検索、フィルター、空状態が読める
- [ ] 記録タブの統計、カレンダー、設定が読める
- [ ] 観察サマリーの小さい補助文字がグラデーションの全域で読める
- [ ] 植物詳細のナビゲーションバーとステータスバーが読める
- [ ] 危険・注意・一般状態が色だけに依存しない
- [ ] 選択中フィルターがチェック/枠/読み上げでも判別できる
- [ ] 現物チェックの選択中状態が色面だけでなくチェック/枠でも判別できる
- [ ] Dark Modeの珍しさ色上にあるチェックなど小アイコンが埋没しない
- [ ] 無効ボタンと有効ボタンを色以外の状態でも理解できる
- [ ] Modalを開閉した際に不自然な白フラッシュがない

## Dynamic Type / 大きな文字

最低でも通常、XXXL、Accessibility系の大きな文字サイズで確認する。

- [ ] タブバーのラベルが切れず、ホームインジケータと重ならない
- [ ] 今日タブの「観察を始める / 探す」が必要に応じて縦積みになり、ラベルが切れない
- [ ] 今日タブの観察チャレンジで進捗バーと「受け取る」が必要に応じて縦積みになり、報酬CTAが省略されない
- [ ] 今日タブの統計カードが大きな文字では2列、最大級では1列へ落ちる
- [ ] 最近の観察・季節の注目植物で植物名と注意区分が1行固定で切れない
- [ ] オンボーディング本文がスクロールでき、CTAへ到達できる
- [ ] オンボーディングの戻る/次へ/開始操作が狭幅では縦積みになり、前ページへ戻れる
- [ ] 低い横画面でもオンボーディングの装飾領域が縮み、本文よりCTA到達性を優先する
- [ ] 成長の記録ModalでCTAが常に残り、本文だけスクロールできる
- [ ] 観察結果Modalの保存/再観察CTAへ到達できる
- [ ] 観察結果の画像一致度が最大文字で固定幅に押し潰されず、ラベル・バー・数値を確認できる
- [ ] 現物チェック3択が必要に応じて縦積みになり、文言が省略されない
- [ ] 図鑑が大きな文字では2列、最大Accessibility文字または狭幅では1列へ落ちる
- [ ] 図鑑カード・一覧の植物名、学名、科名が必要に応じて複数行で確認できる
- [ ] 未発見ヒントシートがスクロールできる
- [ ] 記録タブの統計・観察の足あと・設定radio・Modal CTAが最大文字で必要に応じて縦積みになる
- [ ] 観察サマリーで長い名前・称号が破綻せず、統計が必要に応じて縦積みになる
- [ ] 名前変更Modalでキーボード表示中も保存/キャンセルが操作できる
- [ ] エラー画面で再試行ボタンへスクロールでき、Safe Area外へはみ出さない

## VoiceOver / TalkBack

- [ ] タブ名が「今日 / 観察 / 探す / 記録」と意味どおり読まれる
- [ ] 星は装飾を5回読まず、珍しさを1つの意味として読める
- [ ] 安全区分は色名ではなく「一般に食用とされる / 要注意 / 危険・有毒」と読める
- [ ] 今日の観察チャレンジの説明と「受け取る」ボタンを別々にフォーカスでき、親カードがCTAを吸収しない
- [ ] 類似植物の警告を1件ずつ内容まで確認できる
- [ ] 類似種警告の表示時に同じ安全情報が二重に割り込んで読み上げられない
- [ ] フィルターの選択状態が `selected` として伝わる
- [ ] 現物チェックがradio groupとして移動でき、選択状態が伝わる
- [ ] 表示切替の現在タブが選択状態として伝わる
- [ ] カレンダーの日付・今日・観察件数を一まとまりで読める
- [ ] 画像や装飾アイコンが不要に読み上げられない
- [ ] Modalで背景要素へフォーカスが抜けない
- [ ] iOS VoiceOverでは、閉じられるModalをAccessibility Escapeで閉じられる
- [ ] iOS VoiceOverでは、オンボーディング2ページ目以降のAccessibility Escapeで前ページへ戻る
- [ ] Android TalkBackでは、システムの戻る操作で閉じられるModalが `Modal.onRequestClose` 経由で閉じられる
- [ ] Android TalkBackでは、オンボーディング2ページ目以降のシステムの戻る操作で前ページへ戻る
- [ ] 成長の記録Modalを開いた直後、「閉じる」ではなく「成長の記録・レベル・称号」へフォーカスする
- [ ] 観察サマリーを開いた直後、「閉じる」ではなく「観察サマリー」見出しへフォーカスする
- [ ] 観察結果Modalを開いた直後、植物候補名・注意区分・候補数の文脈へフォーカスする
- [ ] 観察結果で別候補を選んだ後、フォーカスが勝手に結果見出しへ戻らず選択操作の文脈を維持する
- [ ] オンボーディングの「次へ / 戻る / 安全ガイド」後は、新しいページの見出しへ1回だけフォーカスし、ページ情報を二重読み上げしない
- [ ] エラー画面へ切り替わった時、失敗した元画面ではなくエラー見出しへフォーカスする
- [ ] 処理中ステータスが同じ内容を重複して何度も読み上げない

## キーボード / Web

- [ ] Tab / Shift+Tabで主要操作をDOM順と意味順に移動できる
- [ ] カード全体とカード内の補助操作（例: お気に入り）がネストしたinteractive elementになっていない
- [ ] `:focus-visible` がLight/Dark双方で明瞭に見え、マウス操作時には不要なリングを常時表示しない
- [ ] Modalを開いた時にフォーカスがModal内へ移り、閉じた時は起点の操作へ戻る
- [ ] Web narrow / split viewでModalのCTAが画面外へ到達不能にならない

## Reduce Motion

- [ ] XPバー更新が情報を失わず即時反映される
- [ ] オンボーディング切替がアニメーションなしでも理解でき、見出しへのフォーカスも成立する
- [ ] Reduce Motion設定をオンボーディング表示中に切り替えても、現在ページが1ページ目へ勝手に戻らない
- [ ] 成長の記録Modalがアニメーションなしで正しく表示され、初期フォーカスが内容へ移る
- [ ] 観察結果の珍しい発見演出が停止しても情報階層・絵文字サイズが維持される
- [ ] カメラのスキャンライン/パルス停止後も処理状態が文字で分かる
- [ ] Skeletonは点滅せず静止状態でも「読み込み中」の画面構造を邪魔しない
- [ ] Webでは `prefers-reduced-motion: reduce` を切り替えるとReact Native側の演出とCSS transition/animationの両方が抑制される

## ナビゲーション / セッション継続

- [ ] 4タブ間を移動して戻っても、各タブの自然なスクロール・入力状態が不用意に初期化されない
- [ ] アプリをバックグラウンド→フォアグラウンドへ戻しても、現在タブが勝手に「今日」へ戻らない
- [ ] 日付をまたいだ後の最初のアプリ復帰で日次データは更新されるが、現在タブ・入力途中の状態を強制remountで失わない
- [ ] 日付更新後、今日タブの日次チャレンジと記録タブのカレンダーが新しい日付へ更新される
- [ ] キーボード表示時にタブバーが隠れ、キーボードを閉じると自然に復帰する

## 観察フロー

### カメラ権限

- [ ] 初回許可要求の理由が「撮影・候補確認・観察記録」と一致する
- [ ] 一度拒否した後、再要求可能なら再要求できる
- [ ] 再要求不可なら設定アプリへ案内される
- [ ] 権限画面にも安全説明がある

### 撮影

- [ ] 1枚目を片手で撮影できる
- [ ] 追加写真を撮影しても主CTAが画面外へ押し出されない
- [ ] 写真削除・部位変更のタップ領域が十分
- [ ] 最大枚数到達時に理由が分かる
- [ ] 処理中は連打できず、状態が文字で分かる

### 候補確認

- [ ] AI候補を確定結果のように表示しない
- [ ] 複数候補を安全情報込みで比較できる
- [ ] 危険候補・有毒類似種が候補内にある場合、判断前に警告される
- [ ] 候補カードの読み上げに植物名・注意区分・画像一致度・選択状態が含まれる
- [ ] 現物チェックの一致/不一致/未確認が色だけに依存しない
- [ ] 現物チェックを大きな文字でも3択すべて読んで選べる
- [ ] デモ結果は保存・XP・図鑑へ反映できない
- [ ] AI接続失敗から再試行できる
- [ ] 特定不能でも未同定観察として記録できる

## 探す / 図鑑

- [ ] 検索は和名・英名・学名で利用できる
- [ ] 未発見植物の名前は検索から漏れない
- [ ] 0件時に検索/フィルターを一括解除できる
- [ ] 小型画面・大きな文字でカードが過密にならない
- [ ] 最大級文字で植物名が必要に応じて複数行表示される
- [ ] 最終行のカードだけ不自然に横長にならない
- [ ] Grid / List / Family表示切替が明確
- [ ] フィルター選択は色だけで判断しない
- [ ] 未発見ヒントから確定名称を漏らさない

## 記録

- [ ] 長いプレイヤー名でもヒーローが破綻しない
- [ ] 名前が空、または変更なしの場合は保存できない
- [ ] 名前入力20文字制限が視覚的にも分かる
- [ ] 観察履歴検索の0件表示が自然
- [ ] 再訪予定から植物詳細へ遷移できる
- [ ] 削除操作は破壊的操作として確認を挟む
- [ ] 観察サマリー共有文がアプリ内の表示内容と矛盾しない
- [ ] 観察サマリーの3統計・季節・継続表示が大きな文字でも衝突しない
- [ ] データエクスポートに写真バイナリや秘密情報を含めない

## 植物詳細

- [ ] 撮影写真がある/ない両方でヒーローが成立する
- [ ] 危険・注意植物の安全文言が候補前提で正確
- [ ] 「まず知る → 見分ける → 深く学ぶ → 暮らしに活かす」の順序が自然
- [ ] 再訪予定を設定・解除できる
- [ ] 観察メモの保存済み状態が時間で勝手に消えず、編集を再開した時だけ未保存へ戻る
- [ ] 関連植物カードの文字が読める
- [ ] 外部出典リンクのドメインが分かる

## エラー / 空状態

- [ ] ルート描画エラーで白画面にならず再試行できる
- [ ] 大きな文字でもエラー本文と再試行へ到達できる
- [ ] エラー発生時にスクリーンリーダーのフォーカスがエラー見出しへ移る
- [ ] ノッチ・ステータスバー・ホームインジケータがエラー復旧UIへ重ならない
- [ ] 図鑑0件が「壊れた」と誤認されず、解除行動を提示する
- [ ] 動的に空状態へ切り替わった時、タイトルがpolite live regionとして1回伝わる
- [ ] ネットワーク失敗と植物特定不能を別の状態として伝える
- [ ] OS権限拒否とAI同意オフを別の状態として伝える

## 安全表示

- [ ] 今日 / 観察 / 探す / 記録 / 植物詳細など、安全説明が必要な主要画面で共有 `DisclaimerBanner` が表示される
- [ ] 権限拒否、空状態、エラー状態、Modalなど別状態へ遷移しても、採取・摂取判断に関わる導線では安全説明へ到達できる
- [ ] 通常版・compact版とも「必ず専門家に確認を」が可視テキストとして表示される
- [ ] VoiceOver / TalkBackでも「必ず専門家に確認を」が読み上げられる

## リリース前の自動ゲート

次がすべて成功していること。

```bash
npm ci
npm run typecheck
npm run lint
npm test -- --runInBand
npm run build:web
```

さらに `src/theme/__tests__/colors.test.ts` が主要semantic colorの4.5:1コントラスト基準を継続して守り、`src/theme/__tests__/theme.test.ts` がsemantic typographyのsize/line-height対応を回帰防止すること。

- オンボーディングのページ切替時に見出しが1回だけ読み上げられること

- iOS / Androidのカメラ権限拒否→設定遷移
